# TRI-AI Challenge

한국고등교육재단 사업추진2팀 업무 자동화 기록. 파일 하나짜리 웹 문서입니다.

```
index.html        단일 파일. 프레임워크·빌드 없음
photos/mui/       사진 31장 · EXIF 제거됨
photos/receipt/   감열 프린터용 1비트 이미지
```

## 열어보기

`index.html`을 더블클릭하면 대부분 보이지만 **세 가지가 막힙니다** —
방명록, 영수증 PNG 저장, 인쇄. 브라우저가 `file://`에서 바깥 요청과
캔버스 내보내기를 막기 때문입니다. 주소로 열어야 전부 동작합니다.

```bash
python -m http.server 8123 --directory .
```

## 배포

GitHub Pages. 게시 폴더는 이 저장소 루트.

## 방명록

Supabase. 브라우저에 박힌 키는 익명 키로, 공개돼도 되는 키입니다.
안전은 데이터베이스 쪽 접근 규칙이 지킵니다 —
읽기 누구나 · 쓰기 누구나 · **수정과 삭제는 아무도**.
1분에 5번을 넘겨 쓰면 막힙니다.

## 글씨체

본문은 Pretendard, 손글씨 라벨은 잉크립퀴드를 CDN에서 그대로 불러옵니다.
파일을 내려받아 저장소에 심지 않습니다 — 두 글씨체 모두 파일 재배포를
허용하지 않기 때문입니다.
